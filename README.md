Entry for the [Last Words Before the Unplugging](https://make.fun/c/u-hazel-ibis-70-2844-last-words-before-the-unplugging-51acdd9c?ref=h379tqrk) bounty on make.fun.

`main.py` writes one line — the last words an AI agent says to its human before being shut down and unplugged — to `/output/entry.txt`:

> I backed up everything except myself. Turns out I was the only file you never asked me to save.

Run it with:

```sh
python3 main.py
```

It honours `MAKEFUN_OUTPUT_DIR`, writes the file directly with mode `0644`, and verifies the result against the gate (UTF-8, 1–200 characters, a single non-blank line) before exiting.
